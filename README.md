# Капоэйра Магадан

Публичный статический сайт группы: дети от четырёх лет, подростки и взрослые.

GitHub Pages публикует ветку main, корень репозитория. Каждый коммит в main обновляет сайт по прежнему адресу.

HTML, CSS и JavaScript можно редактировать прямо в этом репозитории. Для локального просмотра: python -m http.server 4173. Изображения и локальные шрифты лежат рядом с кодом; лицензии шрифтов — OFL-manrope.txt и OFL-oswald.txt.

Иллюстрации представляют условных персонажей. История группы пока ожидает наполнения. Запись ведёт в существующего Telegram-бота; форма связи скрыта до подключения доставки.
